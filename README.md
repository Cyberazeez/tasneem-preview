# Tasneem Water: prototype preview

Static build of the storefront and admin prototypes, served by GitHub Pages. This repo holds only compiled output. The source lives in the private `tasneem-water` repo.

- Store: `/ar/` or `/en/`
- Admin: `/ar/admin/` (demo login on the sign-in page)

All products, prices, orders and contact details are placeholders. Orders live in the browser's local storage only.
